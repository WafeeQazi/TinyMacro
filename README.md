# TinyMacro

## What it can do

- Records left, middle, and right mouse clicks - including click-and-drag
- Records scroll wheel input and cursor movement
- Records keyboard input, including how long a key was actually held down
- Save and load macros as `.tmacro` files
- Repeat playback a set number of times, or loop it forever
- Speed playback up or slow it down without re-recording anything
- Pause and resume mid-playback, plus a Stop Playback button in case something needs to stop immediately

## Using it

1. Open TinyMacro
2. Click **Record**
3. Do the thing you want repeated - click around, type, drag, scroll, etc.
4. Click the same button again to **Stop**
5. Click **Play**

Use **File -> Save** to keep a macro for later, and **File -> Open** to load one back in. Repeat and Speed settings are under "Playback Options."

Hotkeys:
- **Ctrl+Alt+F9** - Record / Stop
- **Ctrl+Alt+F10** - Play / Pause / Resume
- **Ctrl+Alt+F11** - Stop Playback
